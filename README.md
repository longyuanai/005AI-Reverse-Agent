# AI-Reverse-Agent

> AI reverse-engineering helper — Stage-1 happy path.
> Seventh project of the **longyuanai AI Security Agent suite**.

## What it does (PoC)

Parses a synthetic fake PE32 binary, builds a function inventory by
joining the import directory with the local function table (and the PE
entry point), asks the LLM (via `shared-llm-core`) for a one-line
purpose of each, then writes a Markdown report.

```
fake_pe.bin ──► parse_pe ──► PeImage ──► identify_functions
                                                    │
                                                    ▼
                                          IdentifiedFunction[*]
                                                    │
                                                    ▼
                                          LLM Enricher
                                                      │
                                                      ▼
                                          EnrichedFunction[*]
                                                      │
                                                      ▼
                                          Markdown Report
```

## PoC shortcuts

- **Binary format** is a hand-crafted fake PE32 generated by
  `fake_pe.make_fake_pe()`. It contains MZ + PE/COFF/opt headers, three
  sections (.text/.rdata/.idata), an import directory referencing
  `kernel32!CreateFileW`, `user32!MessageBoxW`, `msvcrt!printf`,
  `ws2_32!connect`, and `advapi32!RegOpenKeyExW`, and a tiny fixed-layout
  function table.
- **LLM round-trip**: the analyzer calls the LLM via `shared-llm_core`
  with `response_format={"type": "json_object"}`. When the LLM is
  unavailable, the CLI accepts `--no-llm` to substitute a deterministic
  stub router so demos remain reproducible.

## Install

```bash
cd 005AI逆向Agent
poetry install
```

## Run the demo

```bash
# Offline stub (no network, no LLM endpoint required)
python -m ai_reverse_agent.cli demo --output report.md --no-llm

# Or with a real LLM endpoint (vLLM / Claude / etc.):
export LLM_PROVIDERS=local
export LLM_LOCAL_BASE_URL=http://localhost:8001
export LLM_LOCAL_DEFAULT_MODEL=stub
python -m ai_reverse_agent.cli demo --output report.md
```

## Analyze a binary

```bash
python -m ai_reverse_agent.cli analyze samples/demo-pe.bin --output report.md --no-llm
```

## Test

```bash
poetry run pytest -v
```

All 45 tests use a stubbed router; no live LLM is required.
